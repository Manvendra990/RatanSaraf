# Approved mobile/admin/backend changes — 4 November 2026

This release is based on the uploaded **gwalior.zip**, including the current React **Web** storefront/admin. The earlier standalone admin has not been substituted.

## What changed

1. **Mobile floating contact button** on customer screens: opens an animated vertical contact menu for Call, WhatsApp, Facebook, Instagram, YouTube and Directions. Outside tap / Android back / close collapses it. The panel scrolls on short screens. The button is above the bottom navigation and hidden while typing; authentication/PAN entry screens are excluded.
2. **Home current rate container: sizing only.** Reduced padding, typography scale, margins and corner size. The original JSX, rate sources, Gold/Silver auto-switch, live/store columns and handlers are unchanged. Every existing style colour value is preserved. The reference was used for compact proportions, not to copy its data or colours.
3. **Header layout:** menu + existing logo/name left; Wishlist, Cart and Notifications right. Existing navigation remains. The bottom Profile emoji is replaced by an outlined user icon.
4. **Holdings/history compactness:** grams and current value share a row, smaller spacing/cards/fonts, compact transaction rows. Tap a history record for full notes/payout information; long notes no longer stretch every row. KYC status colours and buy/sell calculations are preserved.
5. **Structured bank payout form for new mobile sells:** Bank Name, Account Holder Name, Account Number, Confirm Account Number and IFSC. Matching account numbers, 9–18 digits, leading zeroes and IFSC format are validated. Confirmation is not stored. Customer/list APIs expose masked details; the account number is encrypted with the existing KYC_ENCRYPTION_KEY. Admin → Sales → Bank details reveals the account for payout review through an authenticated, audited endpoint. Existing sale approval/reservation/paid/reject logic is retained.
6. **Gender / audience:** Add/Edit Product has Men, Women, Unisex and Children. Mobile Categories and Collection have matching filters; admin inventory also has an audience filter. Older products remain unclassified and visible in All; choose an audience when editing them. Selecting Men/Women/Unisex/Children filters by that exact classification.
7. **In-app price notifications:** a committed Gold/Silver price change creates a durable notification with metal, amount per gram and timestamp. Publishing the same numeric rate again does not create a duplicate alert. The mobile bell shows an unread count; its screen includes read/unread, mark all read, manual refresh and older pages. Each customer's read state is separate. Active app polling checks every 15 seconds; notices remain available after reopening/sign-in. Notification IDs are not displayed.
8. **Mobile social settings:** Web admin → Settings includes Facebook, Instagram, YouTube and Google Maps URLs, alongside existing Phone/WhatsApp fields. Empty links show a friendly unavailable message; Directions can use the existing store map query. Only HTTP(S) social links are accepted.
9. **Additive Prisma migration** `202611040001_mobile_updates`: gender column, optional bank columns and notification/read tables. No reset/reseed, fake notification history or historical price/balance rewriting.

## Scope and compatibility

- Notifications are inside the app. OS/background push delivery was not approved and is not enabled in this release.
- The supplied Web storefront and separate legacy website folders are preserved. Existing legacy `/sip/sales` clients can still use their old payout-details contract; new mobile requests use strict structured fields at `/gold/sales`.
- Bank encryption reuses the existing KYC encryption key. Preserve that exact key and keep database backups with the matching key. No new encryption key is generated during upgrade.
- Existing bank text on old sales is preserved; old requests show legacy details in the admin dialog.
- No real `.env`, uploaded documents, database files, node_modules or generated bundles are included in the delivery ZIP. Your original upload is not used as a database or as a credentials source.
